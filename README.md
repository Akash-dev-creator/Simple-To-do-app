
# 📝 To-Do App

A simple and user-friendly To-Do List application built using HTML, CSS, and JavaScript.

## ✨ Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Clean and responsive UI
- Easy to use

- JavaScript
